# React Hook Form + Zod - Exemplo

Este repositório faz parte de um vídeo criado para exemplificar a utilização do **React Hook Form** em conjunto com **Zod** para validação de formulários em aplicações React.

## 📋 Sobre o Projeto

O objetivo deste projeto é demonstrar de forma prática como implementar formulários robustos e com validação de dados utilizando:

- **React Hook Form**: biblioteca performática para gerenciamento de formulários em React
- **Zod**: biblioteca para validação de schemas e tipagem TypeScript
- **Next.js**: framework React para desenvolvimento web
- **TypeScript**: para tipagem estática e melhor experiência de desenvolvimento

## 🚀 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/danielvalmeida91/yt-rhf-zod-example.git
```

2. Instale as dependências:
```bash
pnpm install
```

3. Execute o servidor de desenvolvimento:
```bash
pnpm dev
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.

## 🛠️ Tecnologias Utilizadas

- [Next.js](https://nextjs.org)
- [React Hook Form](https://react-hook-form.com)
- [Zod](https://zod.dev)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com)
